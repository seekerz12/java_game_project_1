--- Project Details ---

Gameplay FeaturesDynamic Pacing & Multi-Stage Progression: Features a fully side-scrolling Stage 1 with a procedural power-up drop system scheduled for over 5 minutes of continuous gameplay. Upon clearing the required target threshold, the game seamlessly fades into a cinematic Stage 2 Boss Arena.  Advanced Weapon Systems: Players can upgrade from a Default Blaster to a Twin Blaster (Multi-shot) and a specialized Three-Way Spread. Projectile trajectories utilize custom delta-Y parameters for angled flight paths.  Diverse Enemy Behaviors:Alien 1: Features dynamic sprite flipping and targeted horizontal attacks.  Alien 2: Utilizes sine-wave mathematics to generate erratic, wiggling flight paths for both the ship and its projectiles.  Boss Entity: A high-HP final encounter featuring three randomized attack patterns, including a "Rain Attack," a 360-degree "Circle Attack," and a targeted "Shotgun Burst".  Custom Dashboard UI: A real-time heads-up display tracking system speed, dynamic armament states, player health (with critical tension flashing), and a cinematic Boss Health Bar.
